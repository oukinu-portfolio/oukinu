# 王欣羽作品集网站

这是已经整理好的 GitHub Pages 网站文件，首页入口为 `index.html`。

## 文件结构

```text
github-pages-portfolio/
├─ index.html
├─ assets/
├─ .nojekyll
└─ README.md
```

请完整上传整个文件夹中的内容，不要只上传 `index.html`，否则图片将无法显示。

## 部署到 GitHub Pages

1. 登录 GitHub，新建一个公开仓库。
2. 点击仓库中的 **Add file → Upload files**。
3. 将本文件夹里的 `index.html`、`assets`、`.nojekyll` 和 `README.md` 一起上传并提交。
4. 打开仓库的 **Settings → Pages**。
5. 在 **Build and deployment** 中选择 **Deploy from a branch**。
6. Branch 选择 `main`，目录选择 `/ (root)`，然后点击 **Save**。
7. 等待约 1–3 分钟，GitHub 会在 Pages 页面显示网站地址。

## 后续更新

修改作品集后，重新上传新的 `index.html` 和发生变化的 `assets` 文件即可。
